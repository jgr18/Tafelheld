# Tafelheld

Tafels oefenen met een capibara. Draait in de browser op Android en laptop, en is te installeren als app.

- `index.html` – de app
- `config.js` – vul hier je Supabase Project URL en Publishable key in (leeg = proefversie, alleen op dit apparaat)
- `supabase.sql` – één keer uitvoeren in Supabase > SQL Editor
- `manifest.json`, `sw.js`, `icon-*.png` – om de app te kunnen installeren

Zie de handleiding "Tafelheld installeren met Supabase en GitHub" voor alle stappen.
